📊 Social Media Productivity Analysis

1. About the Project

This project focuses on analyzing the impact of social media usage on productivity, sleep patterns, work hours, and daily lifestyle habits using Python-based Exploratory Data Analysis (EDA).

The dataset was cleaned, analyzed, and visualized using powerful Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. Different statistical and visualization techniques were applied to identify patterns, trends, correlations, and outliers within the data.

2. Features

• Data Cleaning and Preprocessing  
• Handling Missing Values  
• Exploratory Data Analysis (EDA)  
• Outlier Detection using IQR  
• Correlation Analysis  
• GroupBy Operations  
• Data Visualization using:
   - Bar Charts
   - Histograms
   - Boxplots
   - Scatterplots
   - Heatmaps

3. Technologies Used

• Python  
• Pandas  
• NumPy  
• Matplotlib  
• Seaborn  
• Jupyter Notebook  

4. Key Insights

• Social media usage impacts sleep patterns and productivity.  
• Different social media platforms show varying user engagement levels.  
• Users with higher social media usage tend to experience changes in daily routine and work habits.  
• Correlation analysis helped identify relationships among numerical features.  

5. Conclusion

This project demonstrates how Exploratory Data Analysis (EDA) can be used to understand user behavior, productivity trends, and the influence of social media on lifestyle habits through meaningful visualizations and statistical analysis.
